📖 How DSA is Used in This Game

📚 1. Stack — LIFO (Last In, First Out)

The Stack stores the player's actions. Whenever an action is performed, it is pushed onto the stack. When Undo is selected, the most recent action is popped first. This demonstrates LIFO.

push()pop()Top = latest action

👾 2. Queue — FIFO (First In, First Out)

Enemies are placed into a Queue as they appear. The enemy at the front is attacked first and removed using dequeue. New enemies are added at the rear. This demonstrates FIFO.

enqueue()dequeue()Front → first enemy

🎒 3. Linked List

Collected items are stored as nodes in a Linked List. Each node contains an item and a link to the next node. Items can be added dynamically without requiring a fixed-size array.

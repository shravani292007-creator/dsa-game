📚 DSA USED IN THIS GAME

📚 STACK — LIFO:
Every shot is pushed into the Stack. The latest shot can be removed first using Undo.

🚶 QUEUE — FIFO:
Upcoming bubbles wait in a Queue. The first bubble in the Queue is used first.

🔗 LINKED LIST:
Every bubble popped is added to the Linked List, creating a history of popped bubbles.
